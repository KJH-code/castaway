# 애저 아포칼립스 — 받침 떼기 · 줄이기 · 다시 칠하기 · 뼈 심기

사용자가 올린 Meshy 모델(`presets/models/Meshy_AI_Azure_Apocalypse_1015011851_texture_fbx.zip` — FBX 140만 세모 · 뼈 없음 · 받침 붙음)을
게임용 몹 모델 `presets/models/azure_apocalypse.glb` 로 만드는 도구다. 사용자 요청: 받침을 없애고 · 참고 그림(돌 갑옷 + 푸른 에너지) 쪽으로 칠하고 ·
삼각형 20만까지 · 리깅(떠서 움직이므로 다리 뼈는 없음). 공격은 에너지 빔과 팔 휘두르기로 할 것이다.

```sh
sh tools/azure/run.sh presets/models/Meshy_AI_Azure_Apocalypse_1015011851_texture_fbx.zip /tmp/az presets/models/azure_apocalypse.glb
```

필요한 것: python3 + numpy · scipy · scikit-image · pillow · pymeshlab(줄이기 필터가 `libopengl0` 를 찾는다 — 없으면 `apt-get install libopengl0`) · node + playwright(부위 굽기).
처음부터 끝까지 몇 분이다. 같은 입력이면 같은 GLB 가 나온다(난수는 씨앗을 박았다).

## 단계(`run.sh` 차례)

| | 파일 | 하는 일 |
|---|---|---|
| ① | `fbx2obj.py` | FBX 바이너리를 직접 읽어 `orig.npz`(정점 69.7만 · 세모 139.7만 · uv) |
| ② | `comps.py` | **FBX 는 Y 위라고 적혀 있지만 실제는 Z 위다** — (x,z,−y)로 세운다 · 같은 자리 정점 잇기 · 연결 성분(0 = 몸+받침 · 1 = 등 뒤 사슬 · 나머지 = 받침 위 돌·수정) |
| ③ | `vox.py` | 5 mm 칸으로 속 채우기(x·y·z 세 줄 광선 홀짝 투표) |
| ④ | `rock.py` · `cut2.py` | 받침 찾기: 속 칸의 거리(EDT)가 8칸 넘는 두꺼운 덩이 중 바닥 쪽 것 + 얇은 받침판 → 다시 8칸 키움. 사슬·발톱 끝처럼 얇게 닿은 데는 거기서 끊긴다. 그 속(2칸 키운 것)의 세모를 빼고, 5천 세모 밑 조각과 앞쪽 바위 날(z>0.45)을 뺀다 → 112.7만 |
| ⑤ | `dec.py` · `decnpz.py` | pymeshlab `meshing_decimation_quadric_edge_collapse_with_texture` 로 20만 세모(uv 지킴) |
| ⑥ | `vox2.py` · `skel.py` | 줄인 몸을 6 mm 칸으로 다시 채우고 골격선(skeletonize) — 뼈 자리는 이 선 위에서 가슴부터 손끝까지의 최단 경로로 골랐다 |
| ⑦ | `chain.py` | 사슬: 골격선 굵기 0.9 cm 밑 정점끼리 이은 덩이 중 길이 0.18 넘는 것 |
| ⑧ | `halo.py` | 머리 위 고리: 정점을 법선 반대로 관 반지름만큼 밀어 관 가운데 점을 만들고 원 RANSAC(씨앗 1) — 그냥 맞추면 옆을 지나는 사슬에 붙었다 |
| ⑨ | `bones.py` · `rig.py` | 뼈 23 의 자리(모델 좌표) · 뼈마다 속 칸을 따라 잰 거리(다익스트라) |
| ⑩ | `weights.py` | 가중치(아래) |
| ⑪ | `attr.py` · `bake.html` · `bake.mjs` | 부위(갈고리 빛 · 고리 · 사슬)를 정점에 적고 UV 공간에 그려 `regions.png` |
| ⑫ | `recolor.py` | 다시 칠하기(아래) → `alb.png` · `emi.png` |
| ⑬ | `export.py` | GLB(아래) |

## 뼈 23 (부모)

`root` — `pelvis`(허리 아래 치마·잎날 전부 · 다리 뼈 없음) · `spine` — `chest` — `neck` — `head` — `halo`(고리 · 돌릴 수 있게 따로) ·
팔 넷은 모두 `chest` 밑에 `arm*` → `fore*` → `hand*` → `claw*`(갈고리 한 줌을 한 뼈로 — 오므리기). 몹은 **+z 를 본다** —
`R1`·`R2` 는 몹의 오른쪽(−x) 위·아래 팔, `L1`·`L2` 는 왼쪽(+x) 위·아래 팔이다(좌우 높이가 다르다 — 조각이 그렇게 생겼다).
쉼 자세는 모든 뼈의 회전이 0(단위)이다 — 돌리면 곧 세계 축 기준이다. 머리·꼬리 자리는 GLB `extras.bones` 에 적었다.

## 가중치(`weights.py`)

- 속 칸 거리 + **메시 표면으로 이어받기**(칸으로 못 채운 얇은 데 — 갈고리 끝 · 잎날 9,588 정점은 곧은 거리로 가장 가까운 뼈를 받아 곁의 엉뚱한 팔에 붙었다).
- 가까운 뼈 둘을 1/d⁴ 로 섞되 **둘째는 부모·자식만**(허리–척추 · 위팔–척추 · 목–척추는 열어 둠) — 남의 팔끼리 섞이면 찢어졌다.
- **사슬은 몸통 뼈(허리·척추·가슴·목·머리)만** 따른다(1/d²) — 팔에 걸린 사슬이 허리와 팔 사이에서 막대처럼 늘어났다. 팔이 움직이면 사슬은 몸에 남는다.
- **고리**는 관 가운데에서 3.4 cm 안 + 메시를 따라 6 cm 안까지 번진 것 → `halo` 하나에 몫 1.
- **따로 움직일 덩이를 잇는 세모를 뺀다**(1,465장) — 팔 넷 · 허리 아래 · 머리 · 고리 사이(조각이 서로 맞닿아 붙어 있었다 — 가고일과 같은 일).
- 늘어남 재기: `python3 tools/azure/lbs.py '[[{"armR1":[0,0,0.7]}]]'`(작업 폴더에서 · 오일러 XYZ rad) — 세모 변이 1.6·2.5배 넘게 늘어난 수.
  잰 값: 팔 넷 내리고 갈고리 오므림 + 척추·머리·허리 — 2.5배 넘는 세모 841(대부분 사슬이 밧줄처럼 늘어나는 것) · 위팔 내리기 208.

## 칠하기(`recolor.py`)

참고 그림(검푸른 돌 갑옷 판 · 틈에서 새는 푸른 에너지 · 빛나는 갈고리)을 따랐다. 원래 그림의 밝기는 돌결로 그대로 쓴다.

- 남색 바탕 → 보랏빛 슬레이트(0.085·0.078·0.105 ~ 0.40·0.385·0.47) · 결 둘레엔 푸른 빛이 번진다.
- 원래의 밝은 청록 결(가장 밝은 칸 0.60~0.86) → 에너지: 바탕 (0.55·0.86·1.0) · 발광 (0.18·0.55·1.0)×1.15 · 가장 밝은 데는 흰빛.
- 갈고리 → 끝으로 갈수록 빛나는 에너지 발톱(손바닥 끝 25% · 갈고리 뿌리 25% → 끝 100%) · 고리 → 빛나는 고리 · 사슬 → 어두운 쇠(빛 없음).
- UV 섬 밖은 가장 가까운 섬 안 값으로 채운다(안 그러면 이음매에 검은 금).

## GLB(`export.py`)

- 크기 2.2배 → **키 2.98 m** · 몸 가운데(x,z)가 원점 · 맨 아래(늘어진 사슬 끝)가 y 0.
- 정점 147,541 · 세모 198,535 · 뼈 23 · JOINTS u8 · WEIGHTS u8 정규화 · 법선 · uv · 바탕·발광 그림 2048 JPEG — **11.1 MB**.
- 재질은 glTF PBR(금속 0 · 거칠기 0.85)이지만 이 게임은 램버트를 쓴다 —
  `new THREE.MeshLambertMaterial({map, emissiveMap, emissive:0xffffff, skinning:true})`.
- **r128 에는 GLTFLoader 가 레포에 없다**(`npm pack three@0.128.0` → `package/examples/js/loaders/GLTFLoader.js`). 게임에 들일 때는 다른 몹처럼
  시험장 파일에 자료를 내장하는 편이 맞다(`file://` 에서 .glb 를 못 읽는다).

## 눈으로 보기

`pose.html` + `pshoot.mjs` — GLB 를 GLTFLoader 로 읽어 램버트로 바꾸고 자세를 잡아 찍는다(GLTFLoader.js · three.min.js · .glb 를 한 폴더에 두고
`python3 -m http.server 8765` 로 띄운 뒤 `node tools/azure/pshoot.mjs 'f=azure.glb&w=420&h=470' '[[{"armR1":[0,0,0.7]},0,8]]' out.png`
— 목록 한 칸은 [자세, 방위°, 고도°, 거리 m, 가운데 y, 가운데 x, 가운데 z]).

## 한계

- 사슬은 몸통에만 붙는다(팔을 따라가지 않는다) · 팔을 크게 들면 어깨 · 목둘레 세모가 늘어난다(선형 스키닝).
- 갈고리는 손마다 한 뼈라 손가락을 따로 못 굽힌다. 다리는 뼈가 없다(허리 아래가 한 덩이로 흔들린다).
