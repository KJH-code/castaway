# 워커 역할 설명

워커별 역할 설명(머리말)은 이제 각 에이전트 파일 본문에 들어 있다. 모델·노력도 그 파일 머리말에 고정돼 있다.

| 워커 | 파일 |
|---|---|
| 설계 | `agents/w-design.md` |
| 증명 작성 | `agents/w-proof-write.md` |
| 증명 검증 | `agents/w-proof-verify.md` |
| 구현 | `agents/w-implement.md` |
| 데이터 처리 | `agents/w-data.md` |
| 실험 코드 | `agents/w-experiment.md` |
| 잡일 | `agents/w-chore.md` |

코드 검증은 워커가 아니라 check 스킬 + `checker-test`(test) / `checker`(review·debug) 에이전트가 맡는다. SKILL.md 4단계 참고.

역할 설명을 바꾸려면 해당 에이전트 파일 본문을 고친다.
