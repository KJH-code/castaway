# memo — 작업 중 떠오른 한 마디를 inbox에 던지기

> 이 레포(CASTAWAY)에서는: 커밋 꼬리 줄은 이 세션 규칙대로 · 모델 이름 금지. 정리는 `/reflect` 가 계통 노트(CLAUDE.md '계통별 노트' 표)로 옮긴다.

## 1. 붙이기

- 노트 폴더: CLAUDE.md에 `notes: <경로>` 줄이 있으면 그 경로, 없으면 `docs/notes/`. 없으면 만든다
- 파일: `<노트 폴더>/inbox.md`. 없으면 만들고 맨 위에 `# inbox — 정리 안 된 메모 (/reflect가 정리한다)` 한 줄
- 끝에 붙인다:

```markdown
- <YYYY-MM-DD> (<브랜치>) <메모 원문 그대로>
```

- 메모는 사용자가 준 **원문 그대로**. 맞춤법 수정·요약·해설·태그를 붙이지 않는다
- 메모가 비어 있으면 파일을 건드리지 않고 "메모 없음"이라고만 말한다
- 비밀값(토큰·비밀번호·키)이 보이면 붙이지 않고 그 사실만 알린다. 레포는 팀원이 다 본다
- 개인적인 메모라 레포에 남기기 싫으면 사용자가 "개인 메모"라고 할 때 auto memory에 저장한다(켜져 있을 때만)

## 2. 커밋

```bash
git add -- <노트 폴더>/inbox.md
git commit -m "memo: <메모 앞 몇 단어>" -- <노트 폴더>/inbox.md
```

- 작업 중인 다른 변경은 섞지 않는다. push는 하지 않는다

## 3. 복귀

- 보고는 한 줄: `memo: <노트 폴더>/inbox.md (<커밋 해시>)`
- 해설·정리 제안을 붙이지 않는다
- 곧바로 하던 작업으로 돌아간다
